# Personal Portfolio

A modern and responsive personal portfolio website built with React.js, Vite, and Tailwind CSS. The portfolio presents my technical skills, selected projects, education, and professional contact information through a clean and structured user interface.

## Overview

This project is designed to showcase my development experience and the technologies I work with as a Full Stack Web Developer.

The portfolio focuses on:

- Responsive and modern UI
- Clean component-based architecture
- Reusable React components
- Project showcase
- Professional skills presentation
- Downloadable resume
- Social and contact links
- Responsive layout across devices

## Key Features

### Hero Section
